### Week 1: Cloud Foundations & Governance Lab

**Duration:** 15/06/2026 – 21/06/2026

#### Objectives

* Complete the initial phase of the AWS theoretical learning path, grasping core cloud computing concepts.
* Understand identity and access management (IAM) and cost control on AWS.
* Begin hands-on setup of the account foundation and basic security policies.

#### Tasks Performed

* **Theory:** Studied the AWS Cloud Journey curriculum focusing on Cloud Foundations, IAM, and Billing. Learned about Regions, Availability Zones, and the shared responsibility model.
* **Hands-on (Lab 1):**
  * Set up AWS Budgets and CloudWatch Alarms to monitor costs, sending email alerts if spending exceeds $1.
  * Configured IAM: created user groups and attached policies instead of relying on the Root account. Enforced Multi-Factor Authentication (MFA).
  * Installed and used AWS CLI and AWS CloudShell to experiment with command-line administration.

#### Outcomes

* **Output:** A fully secured AWS account (Root with MFA, utilizing IAM users) and active billing alerts.
* Gained familiarity with the AWS Management Console and CLI interactions, establishing a solid foundation for the advanced labs in the upcoming weeks.
