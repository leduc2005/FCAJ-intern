### Week 6: Project Ideation, Proposal & Organization Setup

**Duration:** 20/07/2026 – 26/07/2026

#### Objectives

* Finalize the capstone project topic with the team and justify its feasibility.
* Draft the Proposal and design the target Architecture Diagram for the system.
* Establish a secure multi-account environment for the team using AWS Organizations.

#### Tasks Performed

* **Systems Administration (AWS Organizations):**
  * Acting as the team's cloud administrator, I initialized and configured AWS Organizations to centrally manage our member accounts.
  * Configured AWS IAM Identity Center (SSO) to assign appropriately scoped permissions to each team member.
  * Implemented Organization-level AWS Budgets to monitor total expenditure and prevent unexpected billing overruns during the project phase.
* **Project Ideation & Architecture:**
  * Collaborated with the team to finalize the topic: Toxic Text Moderation Platform.
  * Designed and locked in the target Serverless Architecture diagram comprising Amplify, WAF, API Gateway, Lambda, DynamoDB, and Amazon Bedrock.
  * Analyzed compute constraints and cost implications to finalize and submit the Project Proposal.

#### Outcomes

* **Output:** An approved Proposal with a comprehensive architecture diagram (Section 5.3). A secure, multi-account AWS environment fully prepared for the team's development phase.
* Setting up AWS Organizations firsthand provided me with a macro perspective on how real-world enterprises govern large-scale Cloud environments, moving beyond isolated personal accounts.
