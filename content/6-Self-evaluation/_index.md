During my internship at the **First Cloud AI Journey (AWS Vietnam)** from **15/06/2026** to **31/07/2026**, I had the valuable opportunity to learn, practice, and apply my academic knowledge in a real-world environment, specifically through the complete serverless **Toxic Text Moderation Platform** project.

### My Role in the Team

In our team project, I took charge of the **Cloud Infrastructure & Architecture**. Through this role, I significantly improved my programming, analytical, system design, and communication skills. Specifically, my contributions included:

**1. AWS Architecture Design:** Collaborated with the team to analyze project requirements and finalize the Serverless architecture diagram. I determined the data flow from the Frontend (Amplify) through API Gateway, invoking the Lambda (Container), and storing the moderation history in DynamoDB.

**2. Resource Provisioning & Management:** I directly initialized and configured core AWS resources. This included designing the schema and creating the NoSQL table on Amazon DynamoDB, and managing permissions via AWS IAM (Identity and Access Management) to strictly enforce the principle of least privilege.

**3. System Deployment:** Responsible for packaging the AI model into a Container image and pushing it to the Amazon Elastic Container Registry (ECR). Subsequently, I configured an AWS Lambda function to run directly from this image and established a secure integration with API Gateway to expose the endpoint for the Frontend.

### Areas for Improvement
